# Retomar trabajo

## Objetivo
Retomar `[TAREA/FASE]` desde el estado real actual.

## Datos del usuario
Resultado deseado, urgencia, restricciones y cualquier contexto no registrado.

## Leer
`AGENTS.md`, `docs/agent-workflow/status.md`, todos los registros relevantes de `docs/changes/`, changelog, planes de la raíz y las instrucciones del subdirectorio. Después inspeccionar el estado Git y el código actual: la documentación puede estar desactualizada.

## Trabajo
Comparar registros con archivos y configuración; confirmar qué sigue vigente; identificar trabajo incompleto, conflictos, bloqueos y siguiente acción mínima. Auditar el área antes de editar y usar el prompt de planificación/implementación adecuado.

## Límites y validación
Conservar cambios del usuario; no confiar ciegamente en el historial; no inventar resultados, contratos ni comandos. Validar proporcionalmente y revisar diff si se edita.

## Entrega
Estado confirmado, divergencias detectadas, trabajo restante, archivos candidatos, validaciones, riesgos/bloqueos y siguiente paso concreto.
