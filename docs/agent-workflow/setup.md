# Puesta en marcha del entorno de agentes

1. Leer `AGENTS.md` y `docs/agent-workflow/status.md`.
2. Elegir el área: `backend/`, `frontend/` o `backend-laravel/`.
3. Consultar `development.md`, `testing.md` y `architecture.md`.
4. Usar el prompt correspondiente de `prompts/`.

El proyecto no tiene una configuración MCP nativa confirmada ni skills locales descubribles. Por eso esta preparación usa instrucciones raíz, documentación y prompts versionados. No se instala una skill global ni se agrega un archivo MCP inventado.

Requisitos confirmados: Node 22.18.0/npm 10.9.3 y PHP 8.3.29 disponible en Laragon aunque no en PATH. PostgreSQL/MySQL, Redis, Deriv y credenciales quedan pendientes de disponibilidad por entorno.
